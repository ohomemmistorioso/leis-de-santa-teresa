# Outros documentos oficiais de Santa Teresa — ES

Esta pasta é destinada a documentos públicos relevantes que não se encaixem claramente nas categorias de leis, decretos, leis complementares, resoluções, portarias, códigos municipais ou planos municipais.

## O que pode entrar aqui

- Relatórios e diagnósticos oficiais;
- manuais e documentos administrativos publicados pela Prefeitura ou pela Câmara;
- anexos independentes que acompanhem atos normativos, quando não estiverem junto do ato principal;
- documentos institucionais e materiais públicos de planejamento que não sejam um plano municipal formal.

## Critérios

- Priorize fontes oficiais da Prefeitura ou da Câmara Municipal.
- Registre título, órgão responsável, data (se disponível) e URL original.
- Não inclua dados pessoais desnecessários.
- Não apresente um documento como lei ou norma se ele não tiver essa natureza.
- Se não houver documentos conferidos para adicionar, mantenha esta pasta com o README até encontrar material adequado.
