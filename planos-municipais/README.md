## Organização sugerida

Use um arquivo por plano, por exemplo:

- `plano-diretor-lc-031-2020.md`
- `plano-municipal-cultura-2659-2016.md`
- `plano-municipal-turismo-2658-2016.md`
- `plano-municipal-saneamento-basico.md`

> Os nomes acima são sugestões. Confira o número, a data, a versão, os anexos e as eventuais alterações na fonte oficial antes de fechar cada arquivo.
