# Modelo de registro de norma

Copie este modelo para documentar uma norma no catálogo.

- **Tipo de norma:** [lei, decreto, resolução, portaria etc.]
- **Número:** [número oficial]
- **Ano:** [ano]
- **Data de publicação:** [data, se confirmada]
- **Ementa:** [resumo oficial ou transcrição fiel]
- **Arquivo local:** [caminho relativo dentro do repositório]
- **Fonte oficial:** [URL direta da publicação]
- **Anexos:** [incluídos / ausentes / não se aplica / verificar]
- **Conferência do texto:** [conferido / extraído automaticamente / pendente]
- **Observações:** [alterações, lacunas ou outras notas verificadas]

> Não preencha dados por suposição. Se algo não estiver confirmado, escreva “pendente de verificação”.
