## Como atualizar

Ao adicionar um documento:

1. Confira o número, o ano, a ementa e a categoria na fonte oficial.
2. Salve o documento na pasta correspondente, mantendo o nome do arquivo claro.
3. Adicione uma linha à tabela acima com o caminho relativo e o link oficial.
4. Registre se o texto foi extraído de PDF, se há anexos ausentes ou se a conferência está pendente.
5. Não afirme que uma norma está vigente sem verificar alterações, revogações e consolidações.
