# Sobre o catálogo

Este diretório é o índice geral dos documentos organizados no repositório `leis-de-santa-teresa`.

O catálogo pode conter registros incompletos enquanto a pesquisa estiver em andamento. Campos desconhecidos devem ficar marcados como pendentes, em vez de serem adivinhados.

Consulte [`README.md`](README.md) para ver a tabela de documentos e os links oficiais.
